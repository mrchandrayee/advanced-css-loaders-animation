Complete runnable recreation of the uploaded 27.13-second screen recording.

## Five loaders shown in the video

1. **Neon Orbital** — three overlapping neon rings, cyan/magenta/yellow glow, independently timed 3D rotation.
2. **Liquid Blob** — a coral-to-teal gradient shape morphs through changing border-radius values while rotating.
3. **3D Flip Box** — a purple square flips in 3D using perspective and rotateX/rotateY keyframes.
4. **Equalizer Wave** — five mint-green bars stretch to different heights with staggered animation delays.
5. **Radar Pulse** — a coral dot emits two expanding, fading circular pulses.

## Visible source code captured from the video

The HTML structure and main CSS declarations for all five examples are reproduced in the page's code panels. The readable declarations include:

- `.neon-orbital`, `.ring`, `spin-3d`
- `.liquid-blob`, `morph`, `spin`
- `.flip-box`, `flip`
- `.wave-loader`, `stretch`
- `.radar-pulse`, `radar`

Some tiny characters in the recording are too small to read reliably. Where needed, values have been reconstructed to match the visible animation and make the project function as a standalone page.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in Chrome, Firefox, Safari, or Edge.
3. All five animations start automatically.

No npm install, build process, server, external font, image, or JavaScript library is required.

## Project structure

- `index.html` — five loader previews and their HTML/CSS code panels
- `style.css` — full layout and animation definitions
- `script.js` — tiny readiness hook; animations are CSS-powered
- `README.md` — source notes and instructions
